# 이세계 생존기
2D 픽셀 아트 · 탑뷰 · 브라우저 기반 이세계 생존 RPG 프로토타입.

## 현재 구현
- WASD / 방향키 이동
- 태블릿 터치 조이스틱 및 공격 버튼
- 슬라임 추적과 접촉 피해
- 근거리 공격, 경험치, 레벨업
- 행동 반복에 따른 스킬 숙련도와 레벨 성장
- 스킬 데이터를 별도 모듈로 관리

## 실행
GitHub Pages에서 저장소의 `isekai-survival/` 폴더를 배포하거나 정적 HTTP 서버로 실행합니다. ES Modules를 사용하므로 index.html을 file://로 직접 여는 대신 HTTP 서버를 권장합니다.

## 다음 개발 단계
1. 스킬 상세창과 스킬 트리
2. 스킬 간 연계·조합 규칙
3. 인벤토리, 채집, 제작, 장비
4. 맵 확장, 마을, NPC, 퀘스트
5. 자동 저장과 모바일 UI 개선

기획 목표와 실제 구현 완료 수량을 구분합니다.
