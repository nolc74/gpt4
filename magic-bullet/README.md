# 마력탄: 유물의 계승자

브라우저에서 바로 플레이하는 자동 전투 성장 RPG 프로젝트.

## 실행
- GitHub 저장소의 `magic-bullet/` 폴더를 연다.
- 정적 파일 서버에서 `index.html`을 실행한다. ES Modules를 사용하므로 `file://` 직접 실행보다는 GitHub Pages 또는 로컬 정적 서버를 권장한다.

## 현재 구현
- 모바일 가상 조이스틱: 손가락으로 밀어 이동, 놓으면 정지
- PC WASD / 방향키 이동
- 자동 마력탄 발사 및 가장 가까운 몬스터 자동 조준
- 몬스터 추적, 충돌 피해, 처치 보상
- 경험치와 레벨업, 골드 획득
- 캐릭터 능력치 UI 및 골드 강화 메뉴
- 유물 열쇠 1% 드롭 판정
- 브라우저 localStorage 저장
- 일시정지 및 사망 후 재도전

## 설계 원칙
- 주인공의 직접 공격은 마력탄만 사용한다.
- 플레이어 레벨은 무한 성장 구조로 설계한다.
- 마법사 서클은 별도 체계이며 최대 41서클이다.
- 유물은 장착 수 제한 없이 보유 효과가 모두 활성화되는 방향이다.
- 유물 3,001종, 일반 장비 1,000종, 지팡이 100종은 기존 기획을 유지한다.
- 현재 구현된 UI/수치는 핵심 루프의 초기 버전이며, 나머지 확정 기획을 단계적으로 연결한다.

## 구조
- `index.html`: 게임 화면 구조
- `styles.css`: 반응형 UI와 조이스틱
- `src/data.js`: 플레이어/몬스터/기본 규칙 데이터
- `src/engine.js`: 전투, 성장, 저장 로직
- `src/main.js`: 렌더링과 입력/UI 연결
